## 1. Delimited Cross Graph ($DC_{n \times m}$): Definition & Structure

### 1.1 Formal Mathematical Definition
The **Delimited Cross Graph**, denoted by **$DC_{n \times m}$**, is a planar bipartite-like lattice graph composed of alternating staggered vertex rows interconnected by cross edges. The graph is parametrized by two dimensions:
- **Row Dimension ($n$)**: Represents the total number of horizontal rows. It is strictly constrained to be an odd integer ($n \in \{3, 5, 7, \dots\}$) to ensure symmetric upper and lower boundary levels.
- **Column Dimension ($m$)**: Represents the maximum column width across any row. It is constrained to be an integer ($m \ge 2$).

**Row Partitioning**: Let the rows be indexed by $i \in \{1, 2, \dots, n\}$. The vertices within row $i$ are partitioned according to row parity:
- **Odd Rows ($i = 1, 3, 5, \dots, n$)**: Contains exactly $m$ vertices:
  $$V_i = \{ a_{i,1}, a_{i,2}, \dots, a_{i,m} \}$$
- **Even Rows ($i = 2, 4, \dots, n-1$)**: Contains exactly $m - 1$ vertices:
  $$V_i = \{ a_{i,1}, a_{i,2}, \dots, a_{i,m-1} \}$$

Even rows are shifted horizontally by half the horizontal gap ($\text{gapX} / 2$), producing a centered diamond cross lattice between consecutive levels.

### 1.2 Mathematical Counting Formulas
The fundamental topological invariants of $DC_{n \times m}$ are derived analytically as follows:

| Property | Analytical Formula | Evaluation on $DC_{5 \times 4}$ |
|---|---|---|
| **Number of Odd Rows** | $\frac{n + 1}{2}$ | $\frac{5 + 1}{2} = 3$ rows |
| **Number of Even Rows** | $\frac{n - 1}{2}$ | $\frac{5 - 1}{2} = 2$ rows |
| **Total Vertices $|V|$** | $|V| = n \cdot m - \frac{n - 1}{2}$ | $5 \cdot 4 - 2 = 18$ vertices |
| **Total Transition Levels** | $n - 1$ | $5 - 1 = 4$ transition levels |
| **Edges per Transition** | $2(m - 1)$ | $2(4 - 1) = 6$ edges per transition |
| **Total Edges $|E|$** | $|E| = 2(n - 1)(m - 1)$ | $2(4)(3) = 24$ edges |
| **Average Vertex Degree $\bar{d}$** | $\bar{d} = \frac{2\|E\|}{\|V\|} = \frac{4(n - 1)(m - 1)}{nm - (n - 1)/2}$ | $\frac{48}{18} \approx 2.67$ |
| **Graph Density $D$** | $D = \frac{2\|E\|}{\|V\|(\|V\| - 1)} \times 100\%$ | $\frac{48}{18 \times 17} \approx 15.69\%$ |

### 1.3 Edge Connectivity Rules
The edge set $E$ of $DC_{n \times m}$ is generated by connecting adjacent rows through cross edges:
- **Transition from Odd Row $i$ to Even Row $i+1$**:
  Each vertex $a_{i,j}$ connects to $a_{i+1,j}$ and each vertex $a_{i,j+1}$ connects to $a_{i+1,j}$ for $j \in \{1, \dots, m - 1\}$.
- **Transition from Even Row $i$ to Odd Row $i+1$**:
  Each vertex $a_{i,j}$ connects to $a_{i+1,j}$ and $a_{i+1,j+1}$ for $j \in \{1, \dots, m - 1\}$.

### 1.4 React/JavaScript Code Implementation: Graph Construction
```javascript
// Delimited Cross Graph Construction
// Parameters: n (odd rows >= 3), m (columns >= 2)
function createDelimitedCrossGraph(n, m) {
  const gapX = 118;   // Horizontal spacing between column nodes (px)
  const gapY = 86;    // Vertical spacing between row levels (px)
  const padding = 54; // Canvas boundary padding (px)
  const nodes = [];
  const edges = [];

  // 1. Generate Vertices with coordinates
  for (let row = 1; row <= n; row += 1) {
    const isOdd = row % 2 === 1;
    const columns = isOdd ? m : m - 1;
    const offsetX = isOdd ? 0 : gapX / 2; // Stagger even rows
    for (let column = 1; column <= columns; column += 1) {
      nodes.push({
        id: `${row}-${column}`,
        row,
        column,
        x: padding + offsetX + (column - 1) * gapX,
        y: padding + (row - 1) * gapY
      });
    }
  }

  // 2. Generate Inter-row Cross Edges
  for (let row = 1; row < n; row += 1) {
    for (let column = 1; column < m; column += 1) {
      edges.push({ from: `${row}-${column}`, to: `${row + 1}-${column}` });
      if (row % 2 === 1) {
        edges.push({ from: `${row}-${column + 1}`, to: `${row + 1}-${column}` });
      } else {
        edges.push({ from: `${row}-${column}`, to: `${row + 1}-${column + 1}` });
      }
    }
  }

  return {
    nodes,
    edges,
    width: padding * 2 + (m - 1) * gapX,
    height: padding * 2 + (n - 1) * gapY
  };
}
```

## 2. Adjacency and Degree Vector Computation

All centrality algorithms operate on a unified undirected adjacency structure. The helper function `getGraphAdjacency(graph)` builds both the symmetric neighbor list `Map` and the vertex degree `Map`:

```javascript
// Computes undirected adjacency lists and vertex degrees
function getGraphAdjacency(graph) {
  const adjacency = new Map();
  graph.nodes.forEach((node) => adjacency.set(node.id, []));

  graph.edges.forEach(({ from, to }) => {
    if (adjacency.has(from) && adjacency.has(to)) {
      adjacency.get(from).push(to);
      adjacency.get(to).push(from);
    }
  });

  const degrees = new Map();
  graph.nodes.forEach((node) => {
    degrees.set(node.id, adjacency.get(node.id)?.length || 0);
  });

  return { adjacency, degrees };
}
```

## 3. Centrality Measures on Delimited Cross Graph

The system implements four distinct centrality measures plus standard topological labeling:

### 3.1 None (Standard Node Indexing)
- **Definition**: Displays standard matrix-style vertex coordinates $a_{i,j}$, where $i$ is the row index ($1 \le i \le n$) and $j$ is the column index within that row.
- **Purpose**: Serves as the baseline topological ground truth for identifying vertices and tracing paths.
- **Rendering**: Standard subscript SVG rendering `<text>a<tspan dy="3">ij</tspan></text>`.

### 3.2 Leverage Centrality ($l(v)$)
- **Definition**: Leverage centrality considers the degree of a vertex relative to the degrees of its immediate neighbors. A node has positive leverage if its degree exceeds those of its neighbors, and negative leverage if its neighbors are more highly connected.
- **Mathematical Formulation**:
  $$l(v) = \frac{1}{\deg(v)} \sum_{v_i \in N(v)} \frac{\deg(v) - \deg(v_i)}{\deg(v) + \deg(v_i)}$$
  where $v_i \in N(v)$ are the immediate adjacent neighbors of vertex $v$, and $\deg(v)$ is the degree of vertex $v$.
- **Numerical Precision**: In mathematical graph theory research, floating-point rounding errors can obscure subtle structural differences. The implementation utilizes exact reduced fractional arithmetic (GCD reduction) to calculate exact fractional values.

#### Fraction Arithmetic Helper Code:
```javascript
function gcd(a, b) {
  a = Math.abs(a); b = Math.abs(b);
  while (b) { const t = b; b = a % b; a = t; }
  return a;
}

function makeFraction(num, den) {
  if (den === 0 || num === 0) return { num: 0, den: 1 };
  if (den < 0) { num = -num; den = -den; }
  const g = gcd(num, den);
  return { num: num / g, den: den / g };
}

function addFractions(f1, f2) {
  const num = f1.num * f2.den + f2.num * f1.den;
  const den = f1.den * f2.den;
  return makeFraction(num, den);
}

function divideFractionByInt(f, k) {
  if (k === 0 || f.num === 0) return { num: 0, den: 1 };
  if (k < 0) return makeFraction(-f.num, f.den * -k);
  return makeFraction(f.num, f.den * k);
}
```

#### Leverage Centrality Calculation Code:
```javascript
function calculateLeverageCentrality(graph) {
  const { adjacency, degrees } = getGraphAdjacency(graph);
  const rawFractions = new Map();
  const centralityMap = new Map();
  let maxVal = -Infinity;

  graph.nodes.forEach((node) => {
    const degV = degrees.get(node.id) || 0;
    const neighbors = adjacency.get(node.id) || [];
    if (degV === 0) {
      rawFractions.set(node.id, makeFraction(0, 1));
      centralityMap.set(node.id, 0);
    } else {
      let sumFrac = makeFraction(0, 1);
      neighbors.forEach((neighborId) => {
        const degVi = degrees.get(neighborId) || 0;
        const num = degV - degVi;
        const den = degV + degVi;
        if (den !== 0) sumFrac = addFractions(sumFrac, makeFraction(num, den));
      });
      const lFrac = divideFractionByInt(sumFrac, degV);
      rawFractions.set(node.id, lFrac);
      centralityMap.set(node.id, lFrac.num / lFrac.den);
      if (lFrac.num / lFrac.den > maxVal) maxVal = lFrac.num / lFrac.den;
    }
  });

  const maxNodeIds = new Set();
  centralityMap.forEach((val, id) => {
    if (Math.abs(val - maxVal) < 1e-9) maxNodeIds.add(id);
  });

  return { centralityMap, rawFractions, maxVal, maxNodeIds };
}
```

### 3.3 Degree Centrality ($C_D(u)$)
- **Definition**: Degree centrality quantifies the local connectivity of a vertex by measuring the direct number of edges incident to it.
- **Mathematical Formulation**:
  $$C_D(u) = d(u) = \deg(u) = |N(u)|$$
- **Topological Profile**: In the Delimited Cross Graph $DC_{n \times m}$, the 4 corner vertices have degree 2, outer border vertices have degree 2 or 3, and internal diamond vertices have degree 4.

#### Degree Centrality Calculation Code:
```javascript
function calculateDegreeCentrality(graph) {
  const { degrees } = getGraphAdjacency(graph);
  const centralityMap = new Map();
  let maxVal = -Infinity;

  graph.nodes.forEach((node) => {
    const deg = degrees.get(node.id) || 0;
    centralityMap.set(node.id, deg);
    if (deg > maxVal) maxVal = deg;
  });

  const maxNodeIds = new Set();
  centralityMap.forEach((deg, id) => {
    if (deg === maxVal) maxNodeIds.add(id);
  });

  const { ranksMap, uniqueValues, rankGroups, maxRank } =
    computeDenseRanks(centralityMap, String, graph);

  return { centralityMap, maxVal, maxNodeIds, ranksMap, uniqueValues, rankGroups, maxRank };
}
```

### 3.4 Edge-degree Centrality
- **Definition**: Edge-degree centrality assesses communication pathways based on the joint connectivity of incident endpoints minus the shared connecting link.
- **Mathematical Formulations**:
  1. **Edge Degree**: For edge $e = uv$:
     $$d(e) = d(u) + d(v) - 2$$
  2. **Vertex Edge-Degree Sum**: For vertex $u$:
     $$EDS(u) = \sum_{v \in N(u)} (d(u) + d(v) - 2)$$
- **Visualization Rules**: In raw value mode, each edge $e = uv$ displays its edge degree $d(e)$ along the midpoint of the line segment, while each vertex $u$ displays its total edge degree sum $EDS(u)$.

#### Edge-degree Centrality Calculation Code:
```javascript
function calculateEdgeDegreeCentrality(graph) {
  const { adjacency, degrees } = getGraphAdjacency(graph);
  const edgeValues = new Map();

  // Compute d(e) = d(u) + d(v) - 2 for every edge
  graph.edges.forEach(({ from, to }) => {
    const du = degrees.get(from) || 0;
    const dv = degrees.get(to) || 0;
    const key = [from, to].sort().join('|');
    edgeValues.set(key, du + dv - 2);
  });

  // Compute vertex EDS(u)
  const centralityMap = new Map();
  let maxVal = -Infinity;

  graph.nodes.forEach((node) => {
    const neighbors = adjacency.get(node.id) || [];
    let sum = 0;
    neighbors.forEach((nb) => {
      const key = [node.id, nb].sort().join('|');
      sum += (edgeValues.get(key) || 0);
    });
    centralityMap.set(node.id, sum);
    if (sum > maxVal) maxVal = sum;
  });

  const { ranksMap, uniqueValues, rankGroups, maxRank } =
    computeDenseRanks(centralityMap, String, graph);

  return { centralityMap, edgeValues, maxVal, ranksMap, uniqueValues, rankGroups, maxRank };
}
```

### 3.5 Closeness Centrality ($C(v)$)
- **Definition**: Closeness centrality quantifies how close a vertex is to all other vertices in the network by computing the reciprocal of the sum of shortest-path geodesic distances.
- **Mathematical Formulation**:
  $$C(v) = \frac{1}{\text{Farness}(v)} = \frac{1}{\sum_{u \neq v} d(v, u)}$$
  where $d(v, u)$ is the shortest path geodesic distance between node $v$ and node $u$, computed via unweighted Breadth-First Search (BFS).
- **Representation**: The node with the lowest total farness (e.g. $\text{Farness} = 36$) has the highest closeness ($1/36$). The values are formatted as exact unit fractions $1/F$ on vertices.

#### Closeness Centrality Calculation Code:
```javascript
function calculateClosenessCentrality(graph) {
  const { adjacency } = getGraphAdjacency(graph);
  const farnessMap = new Map();
  const centralityMap = new Map();
  let maxVal = -Infinity;

  graph.nodes.forEach((startNode) => {
    const dist = new Map();
    dist.set(startNode.id, 0);
    const queue = [startNode.id];

    // Breadth-First Search (BFS)
    while (queue.length > 0) {
      const curr = queue.shift();
      const d = dist.get(curr);
      const neighbors = adjacency.get(curr) || [];
      for (const nb of neighbors) {
        if (!dist.has(nb)) {
          dist.set(nb, d + 1);
          queue.push(nb);
        }
      }
    }

    let sumDist = 0;
    dist.forEach((d, id) => { if (id !== startNode.id) sumDist += d; });
    farnessMap.set(startNode.id, sumDist);

    const closeness = sumDist === 0 ? 0 : 1 / sumDist;
    centralityMap.set(startNode.id, closeness);
    if (closeness > maxVal) maxVal = closeness;
  });

  const formatCloseness = (val) => {
    const f = Math.round(1 / val);
    return f === 0 ? '0' : `1/${f}`;
  };

  const { ranksMap, uniqueValues, rankGroups, maxRank } =
    computeDenseRanks(centralityMap, formatCloseness, graph);

  return { centralityMap, farnessMap, maxVal, ranksMap, uniqueValues, rankGroups, maxRank };
}
```

## 4. Vertex Display Modes & Multi-Criteria Ranking Synthesis

When Degree, Edge-degree, or Closeness centrality is selected, the application reveals the 'Vertex display' mode selector with four operational modes:

### 4.1 Centrality values (`values`)
- **Behavior**: Directly displays the computed metric (e.g. $2, 4$ for Degree; $8, 20, 24$ for Edge-degree EDS; $1/36, 1/42$ for Closeness).
- **Edge Center Badges**: For Edge-degree centrality, edge midpoint circular badges displaying $d(e) = d(u) + d(v) - 2$ are actively displayed.

### 4.2 Ranking the vertices (`ranking`)
- **Mathematical Rule**: Applies standard dense ranking in descending order (highest value = Rank 1, next highest = Rank 2, etc.). Tied values receive the exact same rank number without skipping subsequent ranks.
- **Edge Suppression**: As specified by requirements, all edge-center midpoint badges are automatically suppressed, keeping the canvas uncluttered and focused on vertex hierarchy.

#### Dense Ranking Algorithm Code:
```javascript
function computeDenseRanks(valuesMap, formatFn, graph) {
  // Extract distinct values sorted descending (highest value first)
  const uniqueValues = Array.from(new Set(valuesMap.values())).sort((a, b) => b - a);
  const ranksMap = new Map();

  valuesMap.forEach((val, id) => {
    const rank = uniqueValues.findIndex((u) => Math.abs(u - val) < 1e-9) + 1;
    ranksMap.set(id, rank);
  });

  const rankGroups = uniqueValues.map((val, idx) => {
    const rank = idx + 1;
    const nodeIds = [];
    valuesMap.forEach((v, id) => {
      if (Math.abs(v - val) < 1e-9) nodeIds.push(id);
    });
    return {
      rank,
      val,
      formattedValue: formatFn ? formatFn(val) : String(val),
      nodeIds,
      nodes: nodeIds.map((id) => {
        const node = graph?.nodes?.find((n) => n.id === id);
        return node ? `a${node.row}${node.column}` : id;
      }),
    };
  });

  return { ranksMap, uniqueValues, rankGroups, maxRank: uniqueValues.length };
}
```

### 4.3 Total influence of the vertices (`total-influence`)
- **Mathematical Formulation**: Synthesizes multi-criteria graph centrality into a single unified influence score by taking the dense ranks across Degree Centrality, Edge-Degree Centrality, and Closeness Centrality and summing them for each vertex:
  $$\text{Total Influence}(v) = R_{\text{deg}}(v) + R_{\text{edge}}(v) + R_{\text{close}}(v)$$
- **Interpretation**: Since dense ranks are 1-based where Rank 1 represents the highest value for each metric, a smaller sum indicates superior combined performance across all three structural criteria. A vertex with Rank 1 across all three centralities achieves the minimum possible sum of 3 (Most Influential).

### 4.4 Positions given to the vertices (`positions`)
- **Mathematical Formulation**: Assigns final positions (Positions 1, 2, 3, ...) by sorting the Total Influence scores in ascending order (lowest sum = Position 1):
  $$\text{Position}(v) = \text{DenseRank}_{\text{asc}}(\text{Total Influence}(v))$$
- **Ascending Ranking**: Position 1 is assigned to the vertices with minimum TI sum (e.g. Sum 3 $\to$ Position 1; Sum 5 $\to$ Position 2; Sum 6 $\to$ Position 3; Sum 9 $\to$ Position 4; Sum 10 $\to$ Position 5).

#### Total Influence and Positions Calculation Code:
```javascript
function calculateTotalInfluence(graph) {
  const degData = calculateDegreeCentrality(graph);
  const edgeDegData = calculateEdgeDegreeCentrality(graph);
  const closenessData = calculateClosenessCentrality(graph);

  const totalInfluenceMap = new Map();
  const breakdownMap = new Map();
  let minSum = Infinity;
  let maxSum = -Infinity;

  // 1. Calculate TI(v) = R_deg(v) + R_edge(v) + R_close(v)
  graph.nodes.forEach((node) => {
    const rDeg = degData.ranksMap.get(node.id) || 0;
    const rEdge = edgeDegData.ranksMap.get(node.id) || 0;
    const rClose = closenessData.ranksMap.get(node.id) || 0;
    const sum = rDeg + rEdge + rClose;
    totalInfluenceMap.set(node.id, sum);
    breakdownMap.set(node.id, { rDeg, rEdge, rClose, sum });
    if (sum < minSum) minSum = sum;
    if (sum > maxSum) maxSum = sum;
  });

  // 2. Ascending order ranking for Positions given to vertices
  const uniqueSums = Array.from(new Set(totalInfluenceMap.values())).sort((a, b) => a - b);
  const positionsMap = new Map();
  totalInfluenceMap.forEach((sum, id) => {
    const position = uniqueSums.indexOf(sum) + 1; // Lowest sum = 1
    positionsMap.set(id, position);
  });

  const sortedGroups = uniqueSums.map((sum, idx) => {
    const position = idx + 1;
    const nodeIds = [];
    totalInfluenceMap.forEach((v, id) => {
      if (v === sum) nodeIds.push(id);
    });
    return {
      position,
      sum,
      nodeIds,
      nodes: nodeIds.map((id) => {
        const node = graph?.nodes?.find((n) => n.id === id);
        return node ? `a${node.row}${node.column}` : id;
      }),
      breakdown: nodeIds.length > 0 ? breakdownMap.get(nodeIds[0]) : null,
    };
  });

  return {
    totalInfluenceMap,
    positionsMap,
    maxPosition: uniqueSums.length,
    minSum,
    maxSum,
    sortedGroups,
    degData,
    edgeDegData,
    closenessData,
  };
}
```

## 6. SVG Canvas Rendering & Export Architecture

The graph visualization engine is built with React and SVG, supporting responsive scaling, pan/zoom, label toggling, and 300+ DPI PNG export:
- **Dynamic SVG Viewport**: Renders nodes and edges as vectorized SVG elements with hardware-accelerated animations (`pop-node`, `draw-line`).
- **Labeling Architecture**: Multi-mode switch in `GraphCanvas` evaluates whether to render coordinates ($a_{ij}$), raw values, descending ranks, total influence sums, or ascending positions.
- **High-DPI PNG Exporter**: Clones the live SVG DOM, inlines CSS styling, renders to an off-screen HTML5 Canvas scaled up by 2x for retina sharpness, and triggers automated file download.

```javascript
          }

          return (
            <g key={node.id} transform={`translate(${node.x} ${node.y})`}>
              <circle r="8" />
              <text y="-20" textAnchor="middle">{displayVal}</text>
            </g>
          );
        })}
      </g>
    </svg>
  );
}
```
